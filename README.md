# 📰 네이버 뉴스 실시간 의제 워드클라우드 생성기

사용자가 입력한 키워드로 **네이버 뉴스를 실시간 크롤링**하고, 뉴스 제목에서 핵심 명사를 추출하여 **워드클라우드(Word Cloud) 이미지**로 시각화하는 파이썬 프로그램입니다.

특정 키워드와 관련된 뉴스에서 어떤 단어가 자주 등장하는지 한눈에 파악할 수 있어, 현재 사회적 의제(Agenda)나 이슈의 흐름을 직관적으로 확인할 수 있습니다.

## ✨ 주요 기능

- **실시간 뉴스 수집**: 네이버 뉴스 검색 결과를 최신순으로 크롤링하여 최대 60개의 제목을 수집합니다.
- **한국어 명사 추출**: 형태소 분석기(KoNLPy의 `Okt`)를 사용해 제목에서 의미 있는 명사만 골라냅니다.
- **데이터 전처리**: 이메일 주소, 특수문자, 한자, 광고성 문구, 불용어(`기자`, `뉴스`, `속보` 등)를 제거합니다.
- **빈도 기반 시각화**: 단어 등장 빈도에 따라 글자 크기를 다르게 표현한 워드클라우드를 생성합니다.
- **이미지 자동 저장**: 결과물을 `output` 폴더에 `PNG` 파일로 저장합니다.
- **크로스 플랫폼 한글 폰트**: Windows(맑은 고딕) / macOS(애플고딕) 환경의 한글 폰트를 자동으로 설정합니다.

## ⚙️ 동작 원리

프로그램은 다음 4단계로 동작합니다.

| 단계 | 함수 | 설명 |
|------|------|------|
| 1. 환경 설정 | `get_font_path()` | 운영체제를 확인하여 한글 폰트 경로를 지정합니다. |
| 2. 크롤링 | `crawl_naver_news()` | 네이버 뉴스를 검색하고 HTML에서 뉴스 제목을 수집합니다. |
| 3. 전처리 & 명사 추출 | `preprocess_and_extract_nouns()` | 제목을 정제하고 형태소 분석으로 명사를 추출 후 빈도를 계산합니다. |
| 4. 시각화 & 저장 | `generate_wordcloud()` | 빈도 데이터를 기반으로 워드클라우드를 생성하고 이미지로 저장합니다. |

## 📋 요구 사항

### Python
- Python 3.7 이상

### Java (필수)
한국어 형태소 분석기 `KoNLPy`는 내부적으로 **Java(JDK)** 를 사용합니다. 실행 전 JDK가 설치되어 있어야 합니다.

> ⚠️ 현재 코드(`main.py`)에는 Windows 기준 Java 경로가 하드코딩되어 있습니다.
> ```python
> os.environ['JAVA_HOME'] = r'C:\Program Files\Java\jdk-26.0.1'
> ```
> 본인의 환경에 맞는 JDK 설치 경로로 수정하거나, 시스템 환경 변수 `JAVA_HOME`이 이미 설정되어 있다면 해당 줄을 삭제하세요.

### Python 라이브러리
| 라이브러리 | 용도 |
|------------|------|
| `requests` | 네이버에서 HTML 소스코드 받아오기 |
| `beautifulsoup4` | HTML에서 뉴스 제목 추출 |
| `konlpy` | 한국어 형태소 분석(명사 추출) |
| `wordcloud` | 워드클라우드 생성 |
| `matplotlib` | 이미지 시각화 |

## 🚀 설치 방법

1. 저장소를 클론합니다.
   ```bash
   git clone https://github.com/isdj20313/news_wordcloud2.git
   cd news_wordcloud2
   ```

2. 필요한 라이브러리를 설치합니다.
   ```bash
   pip install requests beautifulsoup4 konlpy wordcloud matplotlib
   ```

3. (Java 미설치 시) [JDK](https://www.oracle.com/java/technologies/downloads/)를 설치합니다.

## 💻 사용 방법

터미널에서 아래 명령어로 프로그램을 실행합니다.

```bash
python main.py
```

실행 후 분석하고 싶은 키워드를 입력합니다.

```
=========================================
 네이버 뉴스 실시간 의제 워드클라우드 생성기
=========================================
분석하고 싶은 뉴스 키워드를 입력하세요: 인공지능
```

키워드를 입력하면 뉴스 수집 → 명사 추출 → 워드클라우드 생성이 자동으로 진행됩니다.

## 📂 출력 결과

생성된 워드클라우드 이미지는 `output` 폴더에 저장됩니다.

```
output/wordcloud_<키워드>.png
```

예시: 키워드로 `인공지능`을 입력하면 `output/wordcloud_인공지능.png` 파일이 생성됩니다.

또한 데스크톱(Windows/macOS) 환경에서는 생성된 워드클라우드가 **화면 팝업 창**으로도 함께 표시됩니다.

> 💡 GitHub Codespaces 등 화면 표시가 없는 환경에서는 팝업 창이 뜨지 않을 수 있습니다. 좌측 파일 목록의 `output` 폴더에서 생성된 PNG 파일을 직접 클릭해 확인하세요.

## 📝 참고 사항

- 네이버가 잦은 요청을 봇으로 판단해 차단할 수 있어, 요청 사이에 지연 시간(0.3초)을 두고 정상적인 브라우저 User-Agent 헤더를 사용합니다.
- 수집 시간이 길어지지 않도록 **약 4초**가 지나면 그때까지 수집된 데이터로만 진행합니다.
- 뉴스가 수집되지 않을 경우, 다른 키워드로 시도하거나 잠시 후 다시 실행해 보세요.
- **Linux 환경 한글 폰트**: 한글이 깨지지 않으려면 한글 폰트가 설치되어 있어야 합니다. 설치되어 있지 않으면 실행 시 경고가 표시됩니다.
  ```bash
  sudo apt install -y fonts-nanum
  ```
